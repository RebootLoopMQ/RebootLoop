# Phase 2 five-screen journey

The assessment runs on its own page (`demo.html`). A home page introduces the project, and separate pages cover why it matters (including the illustrative carbon scenario), industry status, and evidence and privacy. None of them require completing an assessment.

| Screen | What happens | What it proves or does not prove |
|---|---|---|
| 1. Start | Relatable old-phone prompt and a single assessment action; boundaries and no-account promise are visible. | A public entry point, not device intake. |
| 2. Assess | Seven groups cover ownership, category, power, physical safety, condition, goal and data sensitivity. Live-demo examples can prefill, and all groups are required. | No owner, IMEI, serial number, credentials or files are requested. |
| 3. Route | Deterministic recommendation, reasons, answer summary and a next-action panel. Phone recycling links to MobileMuster; eligible computer recycling links to NTCRS; other items require accepted-item checks. | An external public link is not a partnership, booking or completed handover. |
| 4. Next steps | For ordinary working devices: a residual-risk warning and two action cards. Transfer routes show "Wipe it" (official guidance and an optional checklist) and "Hand it over" (a printable note telling the next owner which setup screen to expect and which account lock means stop). Recycle routes show "Drop it off" with the public pathway; repair routes show "Back it up" and questions for the repairer. Users can mark each card done. Stop and specialist routes instead show **Safe next steps**: escalation actions, the assurance model and no self-erasure checkbox. | A tick or "Mark done" is a self-declaration, not proof of data destruction. The next-owner note is a check the recipient runs themselves, not a certificate. |
| 5. Your impact | Shown only after a normal route. A thank-you message, one estimated figure (a CO₂e range for phones, tablets and computers, or a published recycling figure), links to the relevant public services, and options to save the plan by email, text, share sheet or copy. A session line counts circular routes, safety stops and estimated CO₂e and e-waste. | Estimates for a typical device, applying only once the job is done. No verified carbon savings, diversion or completed circular outcome. See the [evidence ledger](./evidence-sources.md) for which figures still need checking. |

## Two short showcase examples

1. **Working owned iPhone, everyday data, intended for donation.** Route: prepare then donate. The recipient must be confirmed by the user. On Next steps, open Apple's current guidance, then show the printable note for the next owner. The impact screen shows an estimated range, not a verified saving. The app cannot confirm donation or a displaced purchase.
2. **Owned Windows laptop, no power, highly sensitive data, intended for recycling.** Route: professional data review before handover. The Safe next steps screen offers escalation actions and no reset checklist, and there is no impact screen. The app does not promise destruction or recycling.

Other useful cases: university-managed laptop → owner/IT stop; swollen Android phone → physical-hazard stop before any normal handling; standalone SSD/USB → media-specific escalation; a good owned phone intentionally sent for recycling → public MobileMuster pathway after safe preparation.
